# Movement Smoothness Analysis for Reach-to-Target Tasks

This repository contains the programming and analysis component developed during an internship at the EuroMov Digital Health in Motion laboratory. The project focuses on movement smoothness during human reach-to-target tasks and investigates kinematic differences across three participant groups: young controls, aged controls, and post-stroke participants.

The research question is whether movement smoothness, quantified using SPARC and related kinematic metrics, differs across groups performing the same task.

---

## Repository role

This repository contains the data processing pipeline, statistical analysis, and report generation code for the internship project. It does not include the full written internship report, which is hosted in a separate repository: [internship-report-Pichenot-Nolan

       ▼

                │
                ▼
       02_statistical_analysis.Rmd
                │
                └──→ HTML report
```

---

## Notebooks

### `00_test.ipynb`
A preliminary notebook used to test the SPARC implementation on a single subject.

### `01_pipeline_traitement.ipynb`
Processes the raw `.dat` files, segments reach-to-target trials, computes kinematic variables, detects submovements, and exports:
- `metrics_smoothness_export.csv`
- `trajectories_export.csv`

### `02_statistical_analysis.Rmd`
Reads the exported CSV files, performs descriptive and group-level statistical analyses, generates plots, and produces the final HTML report.

---

## Outputs

The pipeline produces:
- structured CSV exports for downstream analysis;
- spatial and kinematic figures;
- summary tables;
- an HTML report containing the statistical analysis and visualizations.
- 
> Output files (HTML report, figures) are not tracked by Git and must be 
> regenerated locally by running the pipeline.
